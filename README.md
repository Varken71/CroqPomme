## Mettre sur GitHub Pages (2 min)
1. Crée repo `croqpomme-pwa` en Public sur github.com
2. Upload TOUS les fichiers de ce dossier (index.html, manifest.json, sw.js, icons/, apple-touch-icon.png, .nojekyll) - Glisse-depose direct
3. Settings > Pages > Source: Deploy from branch, Branch: main, Folder: / (root) > Save
4. Attends 1 min, ton lien sera: https://TON_PSEUDO.github.io/croqpomme-pwa/

## Installer sur téléphone
- **iPhone**: Ouvre le lien dans Safari > bouton Partage (carré flèche en bas) > "Sur l'écran d'accueil" > Ajouter
- **Android**: Chrome > 3 points > "Installer l'application"

L'app marche hors-ligne, en plein écran, et tu peux enfin scroller partout !
